A few mobile first design pointers to remember:
Start developing for a simple mobile view, then add features from there.
While making sure new elements still fit and are easily visible.
Anything that needs to be clicked, should be large enough for a finger.
Same with spacing and seperating touchable elements, to avoid miss"clicks".

Consider what needs to show/hide unecessarily big elements when in mobile view.

Look at icon package for programming languages/technologies.
Added astro-icon with iconify, to have more official looking dev icons for languages/skills.
